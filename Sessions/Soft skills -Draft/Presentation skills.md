# Preparation aspect:

- focus on goals (why are we doing this, explain what is related)
- logical flow and structure the more organised the better
- main points not too much text
- table of contents
- summarise
- Intro-body-conclusion
- Prepare a list of possible questions and address important ones

# The Graphic design aspect
- use ai tools or canva if you are not an expert and go for simple, san-serif style (handling complex designs requires compositional knowledge, 1 main colour for focus, 2 fonts max)
- Use descriptive, infographics

# Presenting aspect
- Feedback
- body language → move around, use props
- eye contact → do not look at slides please
- rehearsals, rehearsals → this is how you build the confidence
- If you don’t know say i don’t know, or I will check later
- The monotonic voice (solved with practice)
	- The low voice
	- The fast talker (sign of nervousness try to calm)
- Probe for questions alot
